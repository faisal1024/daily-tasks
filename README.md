# 3 Daily Tasks Manager

3 Daily Tasks Manager is a focused daily task app for choosing up to three meaningful tasks each day and finishing them without building an endless backlog.

## Support

Need help with the app, have a question, or want to report a problem?

- Email: faisal1024@gmail.com
- GitHub issues: https://github.com/faisal1024/daily-tasks/issues

When requesting support, please include your device model, iOS version, and a short description of what happened.

## Privacy

Task data is stored locally on your device. Notifications are used only for daily task reminders when you enable them.
