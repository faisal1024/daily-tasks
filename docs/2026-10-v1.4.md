# 1.4 (October 2026)

## Lock and unlock

Setting the day is one tap on Today. Changing a set day takes a deliberate
step: it is unlocked in Settings, nowhere else.

**Locking**

- "Set today" stays on Today's status line (and "Set these three" in Ideas when
  the three are picked). Auto-set still sets a day with at least one task at the
  chosen time (noon by default).

**While today is set**

- Today shows a quiet locked state under the card: a lock glyph, the status
  ("Today is set. 2 to go." or "Set automatically at 12:00 PM. 2 to go.") and
  the line "Unlock in Settings". It is one VoiceOver element whose hint is
  "Unlock in Settings". There is no Change button, link or alert on Today.
- Not allowed: adding (typed, Ideas, saved items, routines, last night's draft,
  yesterday's leftovers, brain dump), removing, editing a task's words, and
  "Not today". The store's reducer refuses each of these on a set day
  (`addTask`, `addTasks`, `editTask`, `deleteTask`, `notToday`, and through
  them `addParkedTask`, `addRoutineToToday`, `applyTomorrowDraft`,
  `resolveRollover`), so the rule does not depend on the screen.
- Still allowed: ticking and unticking, timers, break-down steps (add, tick,
  clear), the evening check-in. The widget, Live Activity, Siri and
  notifications are unchanged: they tick and start timers, and never unlock.
- Blocked copy points to Settings: "Today is set. Unlock it in Settings to add
  one." (routines in Ideas, and the saved-for-later sheet).

**Unlocking**

- Settings > Setting the day shows an "Unlock today" row only while today is
  set. Tapping it asks "Unlock today's three?" / "You set these on purpose."
  with "Keep locked" (the prominent, cancel-style button) and "Unlock" (plain,
  not red).
- An explicit unlock holds for the rest of that day: auto-set does not re-lock
  it, even when its time has already passed (`manualUnlockDate`, saved with the
  state and cleared at rollover). A manual "Set today" locks it again, and it
  can be unlocked again the same way.
- Analytics: `day_unlocked` with `source: "settings"`.
